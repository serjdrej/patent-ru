Сюда положите файл rospatent_key.txt с вашим ключом ИС ПП Роспатента —
одна строка, без кавычек, без переноса строки в конце (или с ним, скрипт
всё равно обрежет пробелы).

Этот каталог целиком в .gitignore — ничего отсюда никогда не попадёт
в git-репозиторий, даже случайно.

Ключ отсюда читает только scripts\rospatent.ps1 и только на время своей
работы — он не становится системной переменной окружения Windows и не
виден никаким другим программам на компьютере.
