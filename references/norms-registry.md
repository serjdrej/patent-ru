# Общее: реестр применяемых норм

Загружайте этот файл, когда: нужно проверить формулировку, реквизиты или статус проверки конкретной нормы, применяемой в делопроизводстве по заявке. Разделяемый модуль — самодостаточен, подключается из любого `draft-*.md`.

**Модель — гибрид (решение раздела 8 брифа проекта), с одним исключением по решению заказчика:** для приказа № 107 (раздел 2) и Регламента № 163 (раздел 3) — актов, которые меняются редко, — вшиты дословные выдержки применяемых пунктов. **Для ГК РФ (раздел 1) и Положения о пошлинах № 941 (раздел 4) дословные цитаты и суммы принципиально не вшиваются** — только пересказ, что регулирует норма, ссылка на оригинал и инструкция, что именно проверить на актуальную дату. Причина — эти два источника меняются существенно чаще (пошлины — постановлениями Правительства несколько раз в год; ГК РФ — федеральными законами), и вшитое число или цитата устареют быстрее, чем кто-то заметит.

**Жёсткое правило (дублирует `SKILL.md`):** перед подачей любого документа в ФИПС — перепроверить применённые пункты по действующей редакции первоисточника. Причина: даже тщательная работа накопила ошибки на не до конца сверенных нормах (см. раздел 3 ниже) — вшитая выдержка является рабочей опорой, а не источником истины.

## 5. Источник для проверки обновлений — как искать, а не только куда идти

**Прямые адреса ниже — это последний зафиксированный адрес (08.09.2026), не гарантия.** URL вида `rospatent.gov.ru/ru/documents/<slug>` и `rospatent.gov.ru/ru/activities/dues/table` может измениться при переносе сайта, редизайне или переиздании акта под новым номером. **Если прямая ссылка не открывается или ведёт не туда — не подставлять её по памяти и не гадать новый slug: искать заново по инструкции ниже.** Устойчива именно точка входа и маршрут навигации, а не конечный URL.

### 5.1. Точка входа

**rospatent.gov.ru/ru/docs** («Структура нормативных документов») — стабильная стартовая страница каталога. Организована в двух разрезах: **по юридической силе акта** (Кодексы → Федеральные законы → Указы Президента РФ → Постановления/Распоряжения Правительства РФ → Приказы Минэкономразвития России → Приказы Роспатента → Методические рекомендации → …) и **по объекту ИС/направлению деятельности** («Изобретения, полезные модели», «Пошлины» и т. д. — этот разрез местами ведёт на отдельный сайт `new.fips.ru`, не только на сам rospatent.gov.ru).

### 5.2. Маршрут для ГК РФ, приказа № 107, Регламента № 163, Постановления № 941 (текст)

1. Открыть `rospatent.gov.ru/ru/docs`.
2. В разрезе «по юридической силе» кликнуть нужную категорию: «Кодексы» — для ГК РФ; «Приказы Минэкономразвития России» — для приказа № 107; «Приказы Роспатента» — для Регламента № 163; «Постановления Правительства РФ» — для Постановления № 941.
3. Открывается список нормативных актов этой категории (страница `.../norm_doc_RF#<якорь>` или аналогичная) — на ней есть строка поиска **«Поиск по НПА»** и/или сплошной список актов, каждый подписан полным именем: номер, дата, название в кавычках (например: «Приказ Минэкономразвития России от 21.02.2023 № 107 «О государственной регистрации изобретений»»).
4. Найти нужный акт **по номеру и дате**, а не по названию по памяти (названия могут пересказываться по-разному) — через поиск по странице (Ctrl+F / find-инструмент браузера) по строке вида «№ 107» или «№ 941». Открыть найденную ссылку — попадаете на страницу акта с полным консолидированным текстом и историей редакций по абзацам.

### 5.3. Маршрут для таблицы пошлин (Приложения № 1–2 к Постановлению № 941)

Таблица размеров пошлин физически не входит в текст самого Постановления на сайте — это отдельная страница. Найти её можно двумя путями:
- со страницы самого Постановления № 941 (найдена по маршруту 5.2) — там есть прямые ссылки «Приложение N 1» / «Приложение N 2», ведущие на страницу таблицы;
- либо через раздел «по объекту ИС/направлению деятельности» на `rospatent.gov.ru/ru/docs` → пункт **«Пошлины»** → искать на открывшейся странице формулировку вроде «Таблицы видов юридически значимых действий и размеров пошлин» (в найденной 08.09.2026 версии путь по меню сайта — Главная → Деятельность → Пошлины и платежи → эта таблица).

Страница таблицы показывает собственную дату публикации — сверить, что она датирована не раньше даты вашего расчёта.

## 6. Прикладной вопрос — теперь закрыт, а не открыт

**Продлевается ли трёхмесячный срок ответа на уведомление о нарушении единства?** Раньше — открытый вопрос. После сверки Регламента № 163 (раздел 3) вывод стал определённым:

- уведомление о нарушении единства (п.85/п.148 Регламента, п.18 Правил) и запрос дополнительных материалов (п.84/п.149 Регламента) — **два разных, самостоятельно поименованных административных действия**;
- пошлина 1.14.1 Положения № 941 привязана буквально к «запросу», а не к «уведомлению»;
- **если уведомление о нарушении единства направлено отдельно** (не внутри запроса) — оснований для продления пошлиной 1.14.1 нет, срок практически непродлеваемый;
- **если предложение о выборе группы включено в текст уже отправляемого запроса** (прямо предусмотренный Регламентом сценарий, абз. последний п.85) — этот запрос, а значит и включённое в него предложение, формально подпадает под 1.14.1, и продление в этой части возможно.

**Вывод для `draft-office-action.md`: при получении уведомления — сначала определить, пришло ли оно как отдельный документ или как часть запроса; от этого зависит, есть ли легальный путь продления.** Это по-прежнему прикладной, не нормативный вопрос (наличие «пути» не гарантирует, что экспертиза его применит) — решать с поверенным, но теперь на основе структуры акта, а не догадки.
