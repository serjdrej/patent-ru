# patent-ru

Agent Skill: патентный поиск и делопроизводство РФ (Роспатент / ФИПС) — совмещает поиск аналогов через API Роспатента (включая RU/SU-фонд) с составлением и редактурой документов заявки по Требованиям приказа Минэкономразвития № 107 от 21.02.2023.

Точка входа — [`SKILL.md`](SKILL.md): роутер (≤100 строк), маршрутизирующий задачу на один файл из `references/`. Ветви «поиск» и «написание/редактура» никогда не загружаются вместе.

```
SKILL.md
references/   — 9 модулей: поиск (Роспатент/зарубежные источники/интейк) и текст
                (ответ ФИПС, выделенная заявка, аудит, формула, заявка с нуля,
                реестр применяемых норм)
scripts/      — 4 скрипта, чистый stdlib (кроме pdftotext для google_patents.py):
                rospatent.py, google_patents.py, claims_integrity.py, novelty_check.py
```

**Статус:** не установлен ни в какую библиотеку скиллов — это отдельный проект для последующего ручного импорта (см. `references/norms-registry.md` про модель гибридной проверки норм и `SKILL.md` про жёсткие правила, включая дисциплину ключа `ROSPATENT_API_KEY`).

Регрессионные тесты (см. `references/audit-compliance.md`, раздел 4) прогонялись на живом деле № ⟦НОМЕР ЗАЯВКИ⟧/07(⟦ДОСЬЕ⟧) и проходят.
